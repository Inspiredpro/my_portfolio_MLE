How I work

I run experiments in small steps, compare every model against a baseline with the same validation setup, and pick what ships from the metrics, not from preference.

I use AI coding agents (DeepSeek, Claude and ChatGPT) to write, debug and improve implementations faster, then check the results with benchmark tests before trusting them.
